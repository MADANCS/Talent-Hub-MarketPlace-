# 🚀 JobSleuths: AI-Powered Talent Marketplace (MERN Stack)

**JobSleuths** is a premium, full-stack recruitment platform built with the MERN stack (MongoDB, Express, React, Node.js). It bridges the gap between top-tier talent and innovative organizations by integrating cutting-edge Artificial Intelligence (Google Gemini) and beautiful, interactive UI/UX design.

Designed with a modern, glassmorphism aesthetic and rich micro-animations, this platform offers dedicated, role-based workflows for both **Candidates** and **Recruiters**.

## ✨ Key Features

### 🏢 For Recruiters (Mission Control)
* **AI-Assisted Job Postings:** Automatically generate rich, highly engaging job descriptions using Google Gemini AI by simply entering a job title and required skills.
* **Recruiter Analytics Dashboard:** Visualize candidate funnels, market trends, and applicant conversion rates using beautiful, interactive charts (via Recharts).
* **Candidate Pipeline Management:** Track candidates through stages (Applied, Screening, Interviewed, Offered, Hired) with real-time status updates.
* **Premium UI/UX:** A stunning "Mission Control" interface built with Tailwind CSS and Framer Motion to make daily recruitment tasks feel futuristic and fluid.

### 👨‍💻 For Candidates (Talent Portal)
* **AI Skill Gap Analysis:** Candidates receive intelligent insights comparing their profile against job requirements to highlight strengths and areas for improvement.
* **Automated Resume Scoring:** AI-driven resume parsing and matching to calculate a "Match Score" for specific job listings.
* **Job Discovery & Bookmarking:** Advanced filtering, search functionality, and one-click saving/bookmarking for future reference.
* **Application Tracking:** A dedicated dashboard for candidates to monitor the real-time status of all their submitted applications.

## 🛠️ Technology Stack

* **Frontend:** React.js, Vite, Tailwind CSS, Framer Motion, Recharts, React Router DOM, React Hot Toast
* **Backend:** Node.js, Express.js, MongoDB (Mongoose), JSON Web Tokens (JWT) for secure authentication
* **AI Integration:** Google Generative AI (Gemini Pro API)
* **Architecture:** RESTful API design with strict Role-Based Access Control (RBAC) separating Candidate and Recruiter privileges.

## 💡 Highlights & Technical Achievements
* **Dynamic Dependency Management:** Resolved complex caching structures and React Error Boundary fallbacks during build processes.
* **Complex Data Aggregations:** MongoDB aggregation pipelines for translating time-series application data into actionable UI analytics.
* **Robust Error Handling:** Replaced native browser alerts with custom, reactive Framer Motion modals to prevent silent script blocking in embedded environments.
* **Fully Responsive Design:** The entire application is mobile-responsive without sacrificing any of the premium desktop animations or glassmorphism effects.
